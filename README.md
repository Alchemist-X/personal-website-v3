# Personal Website

A personal website with CLI aesthetic design.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features

- CLI/Terminal window aesthetic
- Multiple pages: Home, Blog, Miscellaneous
- Responsive design
- Dark theme
- Dynamic effects

## Customization

Edit the content in:
- `src/pages/Home.tsx` - Home page content
- `src/pages/Blog.tsx` - Blog posts
- `src/pages/Miscellaneous.tsx` - Miscellaneous content
